# 📖 离线小说阅读器（单文件 HTML）

[English](README.md) · **简体中文**

一个完全**离线、单文件 HTML** 的小说阅读器，纯浏览器运行：小说内容、阅读位置、设置全部保存在浏览器自带的数据库（IndexedDB）中；提供分页阅读、离线中英互译词典、文本解释、浏览器原生语音朗读，以及一键**导出 / 导入备份**，方便把整个书库迁移到另一台设备。

无需服务器、无需联网、无需构建——打开即用。

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 📥 导入 | 支持 `.txt` / `.md`，可多选；自动识别 **UTF-8 / GBK / Big5** 编码；也支持粘贴文本导入；内容哈希去重，重复导入时可选择「重新导入并重置进度」 |
| 💾 持久化 | 所有数据自动写入 **IndexedDB**（刷新不丢失）；受限浏览器自动降级为 localStorage 兼容模式 |
| 🚚 迁移 | **导出备份** → 一份 `.json`（含全部书籍 + 章节 + 进度 + 设置）→ 新设备 **导入备份**（合并 / 覆盖两种方式） |
| 📖 阅读 | 基于 canvas 实测宽度的分页排版；章节/页面导航、目录抽屉、按百分比跳转；键盘、滑动、点击热区翻页；浅色/羊皮纸/深色/护眼绿主题；字号、行距、字体、页宽可调 |
| 🔍 划词 | 划选任意文字弹出工具栏：**翻译 / 解释 / 朗读 / 复制**；可在设置中选择「划词后自动翻译」 |
| 🌐 多语言 | 内置 **中文 / English** 界面一键切换（顶栏 🌐 按钮）；首次打开跟随浏览器语言，之后记住选择 |
| 📚 离线词典 | 词典全部打包在 HTML 内（约 1500 条中英互译 + 成语 + 常用汉字释义），词典面板按标签切换；支持自定义词条的增删 |
| 🔊 朗读 | 浏览器原生语音合成（SpeechSynthesis）；从当前页连续朗读并**自动翻页**，逐段高亮；可调速、选发音人；支持朗读选中文字 |
| ⚙️ 可扩展 | 分层模块化架构、清晰的设计模式、Web Worker 多线程、明确的数据模型（见下文） |

## 🚀 快速开始

1. 下载 **`index.html`**（整个应用就是这一个文件，约 190KB）。
2. 用 Chrome / Edge / Firefox / Safari 等任意现代浏览器双击打开。
3. 点击 **⬆ 导入小说**，选择本地 `.txt` / `.md` 文件即可开始阅读。
4. 书籍、进度、设置会边读边自动保存，刷新页面也不会丢。

> 💡 手机上可把 `index.html` 存到「文件」App 中，随时直接打开。

## 🔁 换设备迁移

**旧设备**

1. 点击 **⇩ 导出备份** → 下载得到 `novel-reader-backup-<日期>.json`。
2. 把这个文件传到新设备即可（`index.html` 本身不用变）。

**新设备**

1. 在新设备打开 `index.html`。
2. 点击 **⇧ 导入备份**，选择刚才的 `.json`。
3. 选择 **合并**（保留新设备已有书籍，只补充备份中不重复的内容与进度）或 **覆盖**（新设备推荐：清空本地数据，完整恢复备份内容）。

全部书籍、章节、阅读位置、设置与自定义词典都会一并恢复。

## 🔎 阅读说明

- **界面语言**：顶栏 **🌐** 按钮可在 **中文 / English** 之间一键切换（按钮、弹窗、词典面板、提示等全部随之切换）。首次打开跟随浏览器语言，之后选择会保存到设置中，并随备份一起迁移。
- **翻页**：键盘 `←` / `→` 或 `PageUp` / `PageDown`；`Home` / `End` 跳章首/章末；触屏左右滑动；可在设置中开启**页面左右点击翻页**；**☷** 打开目录；`«` `»` 切换章节。
- **设置**（⚙）：主题、字号、行距、字体（宋体系 / 楷体系 / 黑体系）、页宽、朗读语速、点击热区、段落缩进、划词行为。
- 工具栏右侧显示**全书进度百分比**；重新打开书籍会自动回到上次位置。

## 🈶 划词翻译 / 解释

在正文中划选文字，弹出工具栏：

- **翻译**：打开词典面板并翻译所选内容（中英文自动识别，按词/短语给出释义，并附整句逐词释义）。
- **解释**：中文智能解释——成语识别、词语分词释义、逐字详解、未收录字提示。
- **朗读**：朗读选中片段。
- **复制**：复制到剪贴板。

以上全部功能**完全离线**，词典内嵌在 HTML 中。

### 词典面板

- 标签：**英译中 · 中译英 · 成语解释 · 汉字详解**。
- 在输入框输入任意文字（或直接划选）回车即可查询。
- 面板底部的**自定义词条**区可长期保存你的词条（例如网文里的自创名词），查询时优先命中——这也是应用「写入/删除数据」能力的一个演示。

## 🔊 语音朗读

- 使用浏览器原生 `speechSynthesis`（支持系统自带中文语音的 Chrome / Edge / Safari 等）。
- ▶ 从当前页开始连续朗读**并自动翻页**，直到全书结束或按 ■ 停止；正在朗读的段落会高亮；工具栏可选语速与发音人。
- 若浏览器无中文语音或完全不支持语音合成，会有明确提示并优雅降级。

## 🧱 架构说明

单文件由 [`src/`](src/) 中的模块化源码拼接而成（见「开发」一节）。自底向上分层：

| 层 | 模块 | 职责 | 设计模式 |
| --- | --- | --- | --- |
| 工具 | `utils` | `$`、debounce、哈希、Toast、对话框、进度层 | 辅助函数 |
| 事件 | `EventBus` | 模块间解耦通信 | **观察者** |
| 存储 | `IndexedDBAdapter` / `LocalStorageAdapter` | 书籍/章节/进度/设置的抽象读写 | **策略 / 仓库** |
| 线程 | `TextWorker` | **Web Worker**（Blob 创建）后台切分章节，自动降级主线程 | 多线程 |
| 数据 | `DataManager` | 书籍/章节/进度/设置的 CRUD、导入与去重 | 存储层的**门面** |
| 词典 | `DictionaryService` | 多部离线词典、中文最大正向匹配分词、自定义词条 | **策略** |
| 排版 | `LineBreaker` + `ChapterPager` | canvas 实测断行与分页（异步、不阻塞） | 纯算法 |
| 阅读 | `Reader` | 导航、渲染、进度保存/恢复、朗读循环、划词 | 控制器 |
| 备份 | `BackupManager` | 备份 JSON 的导出 / 导入 | 序列化 |
| 应用 | `App` | 组装以上模块并绑定 UI | **门面** |

**异步编程**：所有数据库操作均基于 Promise；导入、分页、文件读取全程不阻塞 UI（渐进渲染、`await` 驱动、进度防抖保存、`requestAnimationFrame` 等待布局完成）。
**多线程**：章节切分在 Web Worker 线程中执行（Blob 创建，无需额外文件）；Worker 不可用时自动降级为主线程同 API 执行，侧栏状态栏会显示当前模式（`后台就绪` / `主线程`）。

### 数据模型（IndexedDB `novel_reader_db` v1）

| Store | 主键 | 内容 |
| --- | --- | --- |
| `books` | `id`（基于内容哈希） | 书名、来源、字数、chapterChars[]、chapterTitles[]、进度百分比、时间戳 |
| `chapters` | `[bookId, index]` | 每章标题 + 段落数组 |
| `positions` | `bookId` | chapterIndex、pageIndex、percent、charOffset（字符级偏移，精确恢复） |
| `settings` | `key` | 阅读设置、TTS 语速/发音人、自定义词典、上次打开书籍… |

备份文件结构：`{ app, appVersion, schema:1, exportedAt, counts, data: { books, chapters, positions, settings } }`。

## 🛠 开发

最终交付物是单文件 **`index.html`**。其源码以带注释的分片保存在 [`src/`](src/) 中，由一个小脚本拼接生成：

```bash
# 从 src/part*.html 重新生成 index.html
node src/concat.js

# 对提取出的内联脚本做语法检查（check.js 由 concat 生成）
node src/check.js

# 运行逻辑单元测试（749 项断言：切分、编码识别、词典、
# 分页数学、增删改查、进度往返、备份合并/覆盖）
node src/unit-test.js

# 静态审计：脚本引用的所有 DOM id 必须存在于 HTML 中
node src/id-audit.js

# 可选：本地静态服务器（默认端口 8973），便于用 http 测试
node src/server.js
```

> 改代码：修改对应的 `src/partN.html`，再跑一次 `node src/concat.js` 即可重新生成 `index.html`。

### 扩展指南

- **新增词典**：在 `RAW_DICTS`（part4/5）中追加 `词|释义` 行，或在 `DictionaryService.DICTS` 里注册新的词典。
- **新增数据表 / 增删改查**：在两个存储适配器中新增 store，在 `DataManager` 上暴露方法，并通过 `EventBus` 发/听事件。
- **新增 UI 功能**：组件之间通过 `EventBus` 事件（`books:changed`、`reader:page`、`tts:state`、`settings:changed` …）通信，由 `App` 门面统一装配。

## 🌐 兼容性与注意事项

- 现代浏览器（Chrome / Edge / Firefox / Safari 12.1+）。优先使用 IndexedDB；个别受限环境（如部分无痕模式）自动降级 localStorage 并在容量不足时提示。
- 中文 TTS 语音取决于操作系统与浏览器；Chrome / Edge / Safari 一般自带 `zh-CN` 语音。
- 大体积书籍全部保存在本地存储中；备份以 JSON 完整打包，书库极大时备份文件也会相应变大（离线迁移的正常代价）。
- 若 IndexedDB 与 localStorage 均不可用，应用会明确报错并说明原因。
